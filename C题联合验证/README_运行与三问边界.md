# C题统一代码包：运行顺序与可回答的结论

## 在 Windows 的 `pytorch` 环境运行

把压缩包解压到 `C:\C`，解压后应能看到 `C:\C\C题联合验证\src`、`data\raw`、`data\processed`、`results`。PowerShell：

```powershell
conda activate pytorch
cd 'C:\C\C题联合验证'
python -m pip install -r .\requirements.txt
python -X utf8 .\src\01_parse_trials.py
python -X utf8 .\src\02_raw_qc.py
python -X utf8 .\src\03_preprocess_erp.py
python -X utf8 .\src\04_erp_curves.py
python -X utf8 .\src\05_sensitivity_analysis.py
python -X utf8 .\src\06_q2_feature_model.py
python -X utf8 .\src\07_q2_mechanism_model.py
python -X utf8 .\src\08_q2_mechanism_validation.py
python -X utf8 .\src\09_q3_cognitive_joint_validation.py
python -X utf8 .\tests\validate_event_and_censor.py
```

项目只依赖 Python 科学计算库，不需要 PyTorch。`08` 默认 1999 次完整重训练置换检验，在普通 CPU 上可能需要几分钟；先确认 `01` 和 `03` 运行成功。压缩包内已放入可核验的输出与四份 MAT 原始文件。
也可以在激活环境后运行 `run_all.ps1`，它会按顺序执行 01–09，遇到错误立即停止。

## 事件与行为的正确读法

第 8 通道 ±1 是提示方向。第 9 通道项目一只有 ±1 长段，没有独立的 ±2 点击脉冲；项目二有约在提示后 2.2 秒开始的 ±1 长段和约在 3.2–4.2 秒的 ±2 点击脉冲。项目二的 ±1 与 ±2 同号不等于行为正确，±1 的视觉意义也没有额外的逐试次正确答案核验。01 的 `correct_inferred` 全部留空，03 的 `behavior_correct_inferred` 全部设为 -1。不能从项目一长段持续时间计算反应时，也不能把项目二“提示—点击同号率”解释成正确率。

08 的 356 个干净片段按原始试验编号分五块留出；09 使用**同一四阶段时间基函数和同一分块方式**，并用 MAT 中实际 ±2 点击脉冲前 100 毫秒作为项目二每个试次的截止点。09 在该截止点处截断滤波输入，避免用到点击后数据；长时窗遇到额外硬饱和会再剔除。项目一缺实际点击标记，因此 09 仅报告项目二的点击前定量验证，而项目一仍在 01–08 的视觉阶段内分析。

## 三问的完成程度

| 题目 | 当前能提交的证据 | 仍不能从这些数据推出的结论 |
| --- | --- | --- |
| 第一问 | 01–05 对四组原始三电极信号做质量检查、保留提示相关信息的 ERP 预处理、拟合曲线、窗口敏感性与方向检验；各组数字与图见 `results/03`–`05`。 | 三个额区电极无法单独证实位于中央顶区的经典 P300 来源；保形和伪影去除只能依当前指标验证。 |
| 第二问 | 06–08 提供受约束的 LGN→皮层→头皮*功能前向模型*、四阶段时程、左右 12 维机制特征、留块重建及 1999 次置换。08 的七项方向分类在 BH 校正后均不显著，模型不能作为可靠左右识别器。 | 用 Fz/F3/F4 不能唯一定位 LGN，也没有实际神经元分布或显式皮层反馈回路；参数峰时是预设动力学，不是实测传导时间。 |
| 第三问 | 09 将 08 固定的视觉状态连接到目标后的候选情境、标记关系状态，按真实点击前截止、留出试次检验对 EEG 的预测，明确排除额外长窗饱和。 | 增加候选比较状态没有跨被试稳定的留出增益；缺少海马直接观测、项目一点击时刻及可核验的正确答案，不能宣称验证了海马机制或错误应答模型。 |

**论文写法：**可提出候选认知动力学、给出反例与负结果，不应写“海马信号已提取”“左右三角已经可靠判别”“行为正确率 100%”或“完全解答三问”。08 的 `q2_mechanism_validation_report.txt` 与 09 的 `q3_cognitive_joint_report.txt` 给出留出性能和边界；论文中同时报告显著与不显著结果。

核心复现数字：第一问各文件共保留 85、92、90、89 个试次，单通道左右窗口检验 0/24 通过 FDR；第二问 06 跨被试主模型 BAC=0.515、置换 p=0.306；08 合并任务跨被试 BAC=0.570、置换 p=0.010、七项校正 q=0.070（仍未通过 0.05）；第三问真实点击前窗口剩余 88、89 个试次，候选比较模型相对目标输入模型的识别段误差变化分别为变差 2.88%、改善 0.10%，不能作为稳定的海马机制证据。

## 若要进一步满足题目机制与行为要求

需要先补充逐试次实际三角呈现、正确点击侧与无响应记录，才能定义错误与未及时应答，并为项目一提供真实点击时刻。要检验海马和 LGN 的具体生理来源，需要独立的空间或深部记录、可识别的前向几何约束、更多被试及事先锁定的跨被试验证。对于现有四份 MAT，应以 08–09 的负结果作为模型局限，而不是事后筛选能得到较高分数的参数。
