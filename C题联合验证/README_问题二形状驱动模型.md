本补丁补充“图形的空间结构如何影响神经群响应，并形成三个电极的不同观测”这一数学链条。提供源码、三维方向特征、留出重建、反馈消融、参数敏感性、跨被试分类和完整置换检验。

已经在现有4份记录、356次保留试次上运行完成。新模型补充了候选机制，但**目前没有得到稳定区分真实左右提示的证据，也没有稳定优于旧模型**。这是应该保留在论文中的验证结果，不应通过挑选测试集参数把它改写为成功识别。

## 模型具体补了什么

1. 构造面积和对比度相同的两个镜像三角形。它们是理想化刺激，不冒充实验的逐像素原图。
2. 同一组中心-周边滤波器、4个方向滤波器和3×3感受野提取36维空间输入。
3. 输入驱动LGN样中继和36组兴奋—抑制神经群，包含显式反馈和邻近群体耦合。
4. 群体活动汇聚为6个视野功能池，经固定突触样低通，再由共享混合矩阵映射到Fz/F3/F4。
5. 左右刺激共享全部网络参数和混合系数。方向只改变图形输入，不能为左右类别另设一套自由神经增益。

令 `f_d` 为方向d的空间输入，`σ` 为logistic函数，神经群方程为：

```text
tau_g G' = -G + f_d pulse(t)
tau_e E' = -E + sigma(8E - 10I + 0.8 W E + 4G - 4)
tau_i I' = -I + sigma(10E - 2I - 4)
```

`W` 由感受野距离与方向相似性给定，逐行归一化。E/I活动扣除静息态后汇聚为6池，串联两个读出低通。固定步长RK4在刺激起止处切开积分步，避免积分步长改变刺激时刻。

| 参数 | 固定值 | 含义 |
| --- | --- | --- |
| 网格 | 65×65 | 理想三角形离散图 |
| DoG标准差 | 1、2像素 | 中心与周边空间尺度 |
| 感受野中心 | x、y各取−0.5、0、0.5 | 无量纲视野坐标 |
| 感受野宽度 | 0.30 | 无量纲高斯标准差 |
| 中继时间常数 | 20 ms | LGN样低通 |
| E/I时间常数 | 25/50 ms | 群体响应 |
| 读出时间常数 | 60/100 ms | 两级电流代理低通 |
| 刺激延迟/时长 | 35/200 ms | 时長约0.2秒与题目实验描述一致；延迟是假设 |
| 岭惩罚 | 0.1 | 对6池观测系数惩罚，截距和趋势不罚 |
| 数值子步 | 每256 Hz采样间隔8步 | 另以16步核验数值收敛 |

这些数值是本候选模型的固定假设，不是从三个电极估计出的真实神经生理参数。补丁没有搜索更高测试分数的网络参数。

模型源信号同样经过0.5–30 Hz四阶零相位带通及提示前200 ms基线校正，使拟合对象与03处理后的EEG对应。零相位观测处理本身是非因果的，不能把处理后波形的每个时点解释为真实因果传导时刻。

每池按两幅固定合成图形的响应RMS缩放。训练目标为左右条件平均波形，等权拟合共享映射：

```text
y_c(t | d) = b_c + a_c t + sum_k B_kc z_k(t | d)
```

只在训练折估计 `B、b、a`。6池是视野功能分组；这些系数是有效观测权重，不是通过头部导电模型计算出的解剖导联场。

## 为什么可以形成左右差异

若P交换左右功能池，本模型满足 `z_L = z_R P`，所以：

```text
y_R - y_L = z_R (I - P) B
```

不同图形的局部空间配置可产生不同池活动；观测权重对这些活动的加权可产生头皮差异。如果 `PB=B`，左右池的观测权重对称，则差异可以抵消。代码检验了镜像一致性和对称读出下的抵消。这解释了一种可能机制，并不证明实验中实测差异一定来自该机制。

## 给出的特征表示

对于未知方向的试次，不读取其真实方向来选择模板，而是同时计算L/R候选模板。先用固定时间算子去除线性趋势，再定义三个通道的模板匹配差异特征：

```text
phi_c = sum_t [(EEG_c(t) - midpoint_c(t))
               * (template_R_c(t) - template_L_c(t))] / variance_train_c
```

其中 `midpoint=(template_R+template_L)/2`，模板、通道方差仅由训练折得到。`(phi_Fz, phi_F3, phi_F4)` 为三维表示；总和大于0预测R，否则预测L。这个得分不是已校准的概率。

所有试次的留出特征见 `direction_features_oof.csv`。同一试次在不同验证任务中会出现多行，因为训练数据不同；不能把这些行当作新增独立试次。也不能把不同折估计出的特征直接混合再做一次随机分割，冒充全新外部验证。

## 如何验证

沿用08的原编号20试次一块、两侧额外排除2试次的5折。训练波形用21点三阶SG平滑；测试目标保持为03波形。前几折训练可包含后续试次，因此是留块验证，不是严格未来预测。

| 模型 | 对照用途 |
| --- | --- |
| `shape_wc` | 主模型：空间输入与显式反馈 |
| `shape_blind` | 将左右输入换成两者平均，抹去输入方向差异 |
| `no_feedback` | 去除自激、自抑、I→E及邻近耦合，保留G→E→I前馈 |
| `old_*` | 在相同目标与划分上重跑08名义设置 |

旧模型和新模型的参数数目、惩罚定义不同；它们是预测基准。新模型的消融也不意味着具有相同有效自由度。特别是 `shape_blind` 存在重复列，单个池增益不可唯一辨识。

未知方向识别只检验预先指定的 `shape_wc`：4项记录内留块、3项双向跨被试（项目1、项目2、合并项目）。每项1999次“文件×原20试次块内”置换，每次重新计算标签分组均值并拟合映射；只缓存与标签无关的固定线性运算。已核验缓存计算与直接拟合等价。

BH-FDR覆盖本次7项检验，没有覆盖历史06、08、12的所有探索，因此仍应标注探索性。仅两名被试，不能把356次试验当作356名独立被试。既有03连续预处理和筛选已在整条记录上完成，本次以其固定保留数据为条件。

## 本次参考运行结果

完整模型的留出重建R²如下：

| 记录 | 旧共享时间基函数 | 新空间反馈模型 | 去空间差异 | 去反馈 |
| --- | ---: | ---: | ---: | ---: |
| A项目1 | −1.4276 | −1.5054 | −1.5040 | −1.5157 |
| A项目2 | 0.5291 | 0.4712 | 0.4382 | 0.5280 |
| B项目1 | −1.3853 | −1.3539 | −1.3642 | −1.3497 |
| B项目2 | 0.4746 | 0.3957 | 0.3556 | 0.4711 |

新模型相对去空间差异对照有3/4份记录的描述性增益；相对去反馈对照和旧共享模型都只有1/4份增益，不能宣称复杂反馈稳定提高拟合。

合并项目的双向跨被试平衡准确率为 **0.5396**，置换 **p=0.0725，q=0.5075**。本次7项分类均未通过FDR 0.05。更完整的方程链条并没有自动带来可靠的实测方向识别。

五个时间常数同时乘0.8/1.2的全部重建结果也已保存，没有根据这些测试结果另选主模型。

已完成的程序核验：与08分块清单一致；旧模型复算R²与08一致；左右镜像约束成立；半步长数值误差约3.66×10⁻⁹；分类测试标签不影响本折预测；快速置换与直接拟合一致。`PASS`表示这些程序约束成立，不等于识别显著。

## 与三个问题的关系

本步骤补第二问的候选空间机制与特征构造，不能据此宣称三个问题已经全部得到实证支持。第一问保形证据仍以10–11的注入结果为准；第三问仍缺少独立的逐试次行为正确答案，不能将提示—应答标记一致性直接当作认知正确率。

复现12并核对结果后，下一步可将这套固定视觉状态与09的认知候选模型衔接，检验新增记忆/比较环节是否改善留出预测；同样需要保留负结果，并限制关于海马真实活动及错误作答机制的结论。
